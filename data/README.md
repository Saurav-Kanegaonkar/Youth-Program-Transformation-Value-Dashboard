# Data Sources

Synthetic source-style data for education program business value transformation and scenario tracking.

- `entities.csv`: 36 program initiative records.
- `daily_metrics.csv`: 5,040 program initiative-day metric rows.
- `source_events.csv`: 760 operational events, QA checks, experiments, and stakeholder asks.
- `recommended_actions.csv`: 220 candidate actions with effort and expected lift.
